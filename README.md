# LED-Decke

Steuerung für eine LED-Decke mit 7×9 Kästen und 7 ESP32 (einer pro Reihe).

- `index.html` – Steuerseite fürs Handy (Web Bluetooth). Läuft über GitHub Pages.
- `led_decke_esp32/` – Firmware für alle 7 ESP32 (nur `ROW_NUMBER` unterscheidet sich).
- `ANLEITUNG.md` – Anschluss, Hochladen, Updates über WLAN.
